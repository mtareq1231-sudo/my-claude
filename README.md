# رسالة الترحيب التلقائية

بوت بيرد تلقائياً على العميل **بعد دقيقة** من أول رسالة يبعتها، برسالة فيها تفاصيل
الموقع ورقم التواصل ومدة الشحن والضمان — على **واتساب وماسنجر وانستجرام** من سيرفر واحد.

- ✅ التأخير دقيقة (قابل للتعديل)
- ✅ كل عميل بيستلم الرسالة **مرة واحدة بس** — مش كل ما يبعت
- ✅ الرسايل المجدولة بتفضل موجودة حتى لو السيرفر وقف واشتغل تاني
- ✅ بيتجاهل إشعارات التسليم والقراءة وردودنا الراجعة (echo)

## ليه كود ومش الأدوات الجاهزة؟

رسالة الترحيب في تطبيق واتساب بيزنس وأتمتة Meta Business Suite بترد **فوراً** وبس —
مفيش فيها خيار "استنى دقيقة"، ولا "مرة واحدة لكل عميل". عشان كده الجزء ده لازمه سيرفر.

## التشغيل

### 1. المحتوى

عدّل [`config/business.json`](config/business.json) وحط بيانات المتجر الحقيقية:

```json
{
  "storeName": "اسم المتجر",
  "website": "https://…",
  "phone": "+20 …",
  "shipping": "من 2 إلى 5 أيام عمل",
  "warranty": "ضمان سنة كاملة"
}
```

أي حقل تسيبه فاضي بيختفي سطره من الرسالة. صيغة الرسالة نفسها في
[`src/message.js`](src/message.js).

### 2. المفاتيح

```bash
npm install
cp .env.example .env   # واملأ القيم من لوحة تحكم Meta
```

المفاتيح المطلوبة موضّحة بالتفصيل جوه [`.env.example`](.env.example):
`META_VERIFY_TOKEN`، `META_APP_SECRET`، `WHATSAPP_PHONE_NUMBER_ID`،
`WHATSAPP_TOKEN`، `FB_PAGE_TOKEN`.

### 3. التشغيل والربط

```bash
npm start
```

السيرفر لازم يبقى على رابط HTTPS عام عشان Meta توصله. للتجربة المحلية استخدم
`ngrok http 3000`، وللتشغيل الدائم أي استضافة (Railway / Render / VPS).

بعدها في [developers.facebook.com](https://developers.facebook.com) → التطبيق →
Webhooks، ضيف الرابط `https://your-domain.com/webhook` مع نفس `META_VERIFY_TOKEN`،
واشترك في الحقول دي:

| المنتج | الحقل |
| --- | --- |
| WhatsApp | `messages` |
| Messenger | `messages` |
| Instagram | `messages` |

## التأكد إن كل حاجة شغالة

```bash
curl localhost:3000/preview   # شكل الرسالة قبل ما تتبعت لحد
curl localhost:3000/health    # حالة السيرفر + عدد العملاء اللي اتبعتلهم
npm test
```

## الإعدادات

| المتغير | الافتراضي | المعنى |
| --- | --- | --- |
| `WELCOME_DELAY_SECONDS` | `60` | التأخير قبل الرد |
| `RE_WELCOME_AFTER_DAYS` | `0` | `0` = مرة واحدة مدى الحياة |
| `MAX_LATE_SECONDS` | `600` | يلغي الرسالة لو اتأخرت أكتر من كده |

## ملاحظات

- **نافذة الـ 24 ساعة في واتساب:** الرد المجاني مسموح خلال 24 ساعة من رسالة العميل،
  والدقيقة الواحدة جوه النافذة دي بمسافة كبيرة.
- **بيانات العملاء** بتتخزن في `data/contacts.json` (خارج git). لو مسحته، العملاء
  القدام هيستلموا الرسالة تاني.
- **سيرفر واحد بس:** التخزين ملف على القرص، فلو شغّلت أكتر من نسخة في نفس الوقت
  محتاج تحوّله لقاعدة بيانات.
